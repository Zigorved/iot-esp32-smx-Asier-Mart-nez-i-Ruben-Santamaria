# iot-esp32-smx-Asier-Mart-nez-i-Ruben-Santamaria
Pràctica 3 - Dashboard de monitorització d’un CPD

Druant aquesta practica hem canviat de grup, el nostre grup som Asier Martínez González i Ruben Santamaria Alvarez

En aquesta pràctica es configura una ESP32 com a servidor web per monitoritzar una sala de servidors (CPD). El sistema mostra en una pàgina web les dades dels sensors de temperatura i llum en temps real, i activa alertes visuals i un LED quan es detecten valors de risc.

El projecte també inclou l’organització del desenvolupament amb GitHub, GitHub Projects i documentació tècnica completa del muntatge i funcionament.
